Langkah Menghubungkan Supabase

  1. Buat project gratis di supabase.com.
  2. Buka Project Settings → API, salin Project URL dan anon key, lalu tempel di file supabase-config.js.
  3. Buka SQL Editor di Supabase, jalankan seluruh isi file supabase-schema.sql.
  4. Buka Authentication → Users → Add user untuk membuat akun admin (email & sandi).
  5. Muat ulang halaman ini, lalu login memakai akun tersebut.

Selama konfigurasi masih kosong, website berjalan dalam Mode Demo: data disimpan di browser ini saja (localStorage) dan belum tersinkronisasi ke pengunjung lain.

Tips Keamanan

  • Gunakan sandi minimal 8 karakter dengan kombinasi huruf besar, huruf kecil, dan angka.
  • Jangan memakai sandi yang sama dengan akun lain (email, media sosial, dll).
  • Ganti sandi secara berkala, terutama bila pernah membagikannya kepada orang lain.
  • Pastikan hanya perangkat tepercaya yang mengakses halaman admin ini.
